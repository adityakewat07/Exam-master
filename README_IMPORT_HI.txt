EXAM MASTER — Batch 02 package

FILES
- index.html: updated EXAM MASTER demo with JSON question-bank import and timed practice.
- question-banks/SSC_CGL_Tier1_GA_IndianPolity_Batch01_2026-11-14.json: 25 original bilingual SSC CGL Tier-I General Awareness (Indian Polity) practice questions.

USE ON YOUR PHONE
1. Extract this ZIP.
2. Open index.html in Chrome.
3. Open the Mock Test section.
4. Select SSC CGL.
5. Select General Awareness, Hindi or English, 25 questions and 15 minutes.
6. Under Question Bank Import, choose the JSON file from the question-banks folder.
7. Tap Import JSON Question Bank, then Start Mock Test.

IMPORTANT
- Imported questions are saved in this browser on this device using local storage. They are not uploaded to a server.
- The set contains original practice questions, not official previous-year questions.
- This is one Indian Polity topic set, not a complete General Awareness section or a full 100-question SSC CGL Tier-I mock.
- Login, online payment, central database, and a live published website are not included in this static demo.
